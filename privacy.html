Core Privacy Commitment

Galaxy Apps ("we", "us", or "our") builds software applications for Shopify merchants. When you install any Galaxy Apps product from the Shopify App Store, we access only the minimum Shopify Admin API scopes required to execute the features of that application.

Zero Data Selling We never sell, rent, or share merchant data, theme code, or customer order records with advertisers or data brokers.
Scoped Shopify OAuth All store communication runs over authenticated Shopify Admin APIs using TLS 1.2+ in transit and AES-256 encryption at rest.
No Public AI Training Theme files inspected by ThemeSafe Security are analyzed strictly to generate your store report and never train public AI models.

ThemeSafe - Security - Review read_themes

ThemeSafe - Security - Review (Shopify App Store) provides automated static rule and AI security code review for Shopify themes.

Data We Access via Shopify API

  • Store Metadata: Shop domain (*.myshopify.com), merchant contact email, active billing plan, and timezone to deliver security alerts.
  • Theme Assets (read_themes): Liquid templates, sections, snippets, configuration JSON, and JavaScript/CSS assets belonging to the themes you select for scanning or real-time monitoring.
  • Theme Update Webhooks (themes/update, themes/publish): Event notifications when theme files change so real-time monitoring can compute file diffs and detect unauthorized code edits.

How Rule-Based & AI Security Scanning Processes Code

  • Theme files are first evaluated by our deterministic static rule engine to flag suspicious external domains, obfuscated scripts, or known skimming signatures.
  • When contextual AI code analysis evaluates flagged code snippets, only the relevant code fragment is transmitted over encrypted channels to our enterprise AI inference provider under a zero-data-retention policy.
  • Does not access customer personal data, payment credentials, or checkout session inputs.

ThemeSafe - Auto Backup read_themes · write_themes

ThemeSafe - Auto Backup (Shopify App Store) provides scheduled theme and asset backups with one-click restoration.

Data We Access & Store

  • Theme Files & Store Assets (read_themes, write_themes): Read access creates scheduled or manual snapshots of your themes, templates, sections, and images. Write access is invoked only when you explicitly trigger a theme restore or duplication.
  • Optional Cloud Storage Sync: When you connect your own Google Drive or Dropbox account via OAuth, we use scoped tokens strictly to upload backup archives into your designated folder.

OrderSafe - Auto Backup read_orders

OrderSafe - Auto Backup (Shopify App Store) automates real-time and scheduled backups of Shopify store orders to merchant-controlled email and cloud storage.

Data We Access & Process

  • Order Records (read_orders): Line items, order totals, fulfillment status, and associated customer shipping/billing fields required to generate complete order backup exports.
  • Strict Merchant Ownership: Order backups are generated solely for the store owner's archival, accounting, and recovery purposes and delivered directly to the destination configured by the merchant.
  • No Payment Card Data: We never access raw credit card numbers or banking credentials, which remain handled exclusively by Shopify Payments or your payment gateway.

Data Security, Retention & Deletion

  • Encryption: All OAuth tokens, webhook payloads, and stored backups are encrypted in transit (HTTPS/TLS 1.2+) and at rest (AES-256).
  • Uninstallation & Automatic Purge: When you uninstall a Galaxy Apps application from your Shopify store, Shopify immediately revokes our API access token and dispatches an app/uninstalled webhook. Associated shop tokens are invalidated immediately, and residual operational data is permanently purged within 30 days.

GDPR, CCPA & Shopify Mandatory Compliance Webhooks

Galaxy Apps complies with the European Union General Data Protection Regulation (GDPR), the UK GDPR, the California Consumer Privacy Act (CCPA/CPRA), and Shopify Protected Customer Data requirements.

  • Mandatory Shopify Webhooks: All three applications implement and honor Shopify mandatory privacy webhooks: customers/data_request, customers/redact, and shop/redact.
  • Merchant & Customer Rights: You may request access to, correction of, portability of, or immediate erasure of any personal or store data processed by our applications by emailing support@galaxy-apps.com.
