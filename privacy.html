1. Our Core Privacy Commitment

Galaxy Apps ("we", "us", or "our") builds merchant-first software applications for the Shopify platform. When you install and run any Galaxy Apps product from the Shopify App Store, we access only the minimum Shopify API scopes required to deliver the functionality of that specific application.

Zero Data Selling We never sell, rent, or monetize merchant data, theme code, or customer order records with advertisers or data brokers.
Scoped Shopify OAuth All store communication occurs over authenticated Shopify Admin APIs using TLS 1.2+ encryption in transit and AES-256 at rest.
No AI Training on Your Store Theme files analyzed by ThemeSafe Security are inspected strictly to generate your security report and are never used to train public AI models.

2. ThemeSafe ‑ Security ‑ Review Shopify App Privacy

ThemeSafe ‑ Security ‑ Review (App Store Listing) is an automated security scanning and real-time monitoring app for Shopify themes.

Data We Access via Shopify API

  • Store & Account Metadata: Shop domain (*.myshopify.com), primary merchant contact email, active subscription plan, and timezone to deliver security alerts.
  • Theme Assets (read_themes): Liquid templates, sections, snippets, configuration JSON, and JavaScript/CSS assets belonging to the themes you select for scanning or real-time protection.
  • Theme Update Webhooks (themes/update, themes/publish): Metadata triggered when theme files are modified so real-time monitoring can compute file diffs and detect unauthorized code changes.

How Rule-Based & AI Security Scanning Processes Code

  • Theme code is first evaluated by our deterministic static rule engine to flag suspicious external scripts, obfuscated code blocks, or known skimming signatures.
  • When contextual AI code analysis is invoked on flagged snippets, only the relevant code fragment is transmitted over encrypted channels to our enterprise AI inference provider under a zero-data-retention agreement.
  • Does not access customer PII, payment credentials, or checkout session data.

3. ThemeSafe ‑ Auto Backup Shopify App Privacy

ThemeSafe ‑ Auto Backup (App Store Listing) provides scheduled theme and asset backups with one-click restoration.

Data We Access & Store

  • Theme Files & Store Assets (read_themes, write_themes): Read access is used to create scheduled or manual snapshots of your themes, templates, sections, and images. Write access is used only when you explicitly trigger a theme restore or duplication.
  • Cloud Storage Integrations (Optional): If you connect your own Google Drive or Dropbox account via OAuth, we use scoped tokens strictly to upload backup archives into your designated folder. We never read, modify, or delete unrelated files in your cloud drive.

4. OrderSafe ‑ Auto Backup Shopify App Privacy

OrderSafe ‑ Auto Backup (App Store Listing) automates real-time and scheduled backups of Shopify store orders to merchant-controlled email and cloud storage.

Data We Access & Process

  • Order Records (read_orders): Line items, order totals, fulfillment status, and associated customer shipping/billing fields required to generate complete order backup exports.
  • Strict Merchant Ownership: Order backups are generated solely for the store owner's archival, accounting, and disaster-recovery purposes and delivered directly to the destination configured by the merchant.
  • No Payment Card Data: We never access raw credit card numbers or banking credentials, which remain handled exclusively by Shopify Payments or your payment gateway.

5. Data Security, Retention & Deletion

  • Encryption: All API tokens, webhook payloads, and stored backups are encrypted in transit (HTTPS/TLS 1.2+) and at rest (AES-256).
  • Uninstallation & Automatic Purge: When you uninstall a Galaxy Apps application from your Shopify store, Shopify immediately revokes our API access token and dispatches an app/uninstalled webhook. Associated shop tokens are invalidated immediately, and residual operational data is permanently purged within 30 days (unless an earlier deletion request is submitted).

6. GDPR, CCPA & Shopify Mandatory Compliance Webhooks

Galaxy Apps complies with the European Union General Data Protection Regulation (GDPR), the UK GDPR, the California Consumer Privacy Act (CCPA/CPRA), and Shopify's Protected Customer Data requirements.

  • Mandatory Shopify Webhooks: All three applications implement and honor Shopify's mandatory privacy webhooks: customers/data_request, customers/redact, and shop/redact.
  • Merchant & Customer Rights: You have the right to request access to, correction of, portability of, or immediate erasure of any personal or store data processed by our applications by emailing support@galaxy-apps.com.
